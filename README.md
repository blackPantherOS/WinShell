# WinShell
Qt6 based Win11 like desktop environment what use KF6 modules, C++/Rust
This is not GNOME, KDE, Xfce, or any other existing desktop environment. It is a new, standalone desktop environment that resembles Windows 11.

## Default desktop on the blackPanther OS > v25.1 

- Will it be open source? Maybe, it's possible... 

We intend this primarily for companies and schools to facilitate the gradual transition.

## Toolkit
- Qt6 > 6.11.x
- KF6 modules > 6.3x

# Desktops
- Wayland
- X11/XLibre

# Dependency
- WSExplorer (other blackPanther Project)
